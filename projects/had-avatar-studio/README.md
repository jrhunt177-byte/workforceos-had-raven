# Hunt After Dark — AI Avatar Studio
**Status:** Project proposal, not yet approved or registered with a canonical WorkforceOS Project ID.
**Primary workspace:** iPad → ChatGPT → connected GitHub.
**Parent context:** Hunt After Dark / Raven PublishingOS (HAD-001), with no changes to Raven's active book/case workflow.

## Goal
Develop consent-based, recognizable gothic versions of the owner's likeness for narrated faceless YouTube and TikTok episodes, with optional synthetic narration trained on an owner-provided 3–5-minute voice reference.

## iPad-first production pipeline
1. Upload headshots to ChatGPT on iPad; develop, review, and approve branded avatar portrait variants.
2. Record and upload a clean monologue via iPad, when the selected processing tool supports its input format.
3. Prepare scripts, shot lists, thumbnails, prompts, publishing copy, and metadata in ChatGPT.
4. Store versions and production specs here in GitHub; keep sensitive raw media in access-controlled storage **outside this public repository**.
5. Evaluate hosted/cloud talking-avatar and voice-generation services accessible through iPad browsers; verify cost, commercial licensing, and service privacy before using them.
6. Prefer browser-based video assembly/publishing on iPad. Desktop-only VoiceStudio/SadTalker workflows are optional, not prerequisites.
7. Test a 30-second pilot and obtain human sign-off before extending to 3–5-minute episodes.
